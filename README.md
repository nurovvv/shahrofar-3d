# Skyline Residence – 3D building demo

Interactive 3D model of the riverside complex (three towers on a curved retail podium) for real-estate sales: pick a tower and a floor, open an apartment card with its floor plan and price, then walk around inside it.

Built with [Three.js](https://threejs.org) and [Vite](https://vitejs.dev). Demo data (apartments, prices, statuses) lives in `src/data.js`; floor plans and furniture in `src/layouts.js`.

## The 3D model

The complex is generated by a Blender script, `blender/build_complex.py`, from measurements taken off the aerial marketing render. The camera of that render was recovered from its vanishing points, which gave the site plan, tower positions and rotations, floor heights and roof outlines in metres.

| | Floors | Notes |
|---|---|---|
| Block V | 25 | tallest; 5 podium/lobby levels, 18 typical floors, 2 setback floors with terraces |
| Block B | 21 | colourful glazing on the lower part of the south face |
| Block A | 17 | hotel: green curtain wall, HOTEL fin, two-storey terrace wing |

Also modelled: the podium with shop fronts, glass gallery and copper brand band; the pool deck and playground deck; the river with rocky banks, the bridge avenue, local roads, parking, playground, trees and neighbouring blocks.

Every residential floor is split into a slab object (slab edge, balconies, rails) and a walls object, so the viewer can open a floor up. Each apartment also has an invisible pick volume.

### Rebuilding the model

```bash
pip install bpy shapely          # Blender as a Python module (Python 3.13); or have a Blender 4.2+ binary on PATH
blender/export_web.sh            # -> public/models/shahrofar.glb, src/model/complex.json, build/shahrofar.blend
RENDER=1 blender/export_web.sh   # also renders build/shahrofar.png from the marketing render's camera
```

`build_complex.py` also takes `--view "river aerial" | "avenue street" | "river street"` for other stills. `blender/shahrofar.blend` is a ready-made copy of the scene to open in Blender.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Publish

Every push to `main` is built and published to GitHub Pages by `.github/workflows/deploy.yml`.

## Controls

- **Complex:** drag to rotate, scroll to zoom, hover a tower to see its floors, click a floor (or pick one from the list; switch towers with the Block V / Block B tabs), then click an apartment.
- **Inside:** drag to look around, click the floor to walk there, or use WASD / arrow keys. On touch screens, use the on-screen joystick.
